## 🚀 Project Overview

* **RC25** is the personal portfolio of **Chadarasipalli Ramcharan**, a Computer Science and Engineering student specializing in Artificial Intelligence and Machine Learning at Sir Padampat Singhania University.

* The website brings together my background, technical skills, projects, certificates, gallery, resume, and contact information in one place.

* Visitors can explore individual projects, follow my learning journey, view certificate images, and access my resume.

* The interface supports desktop and mobile layouts, dark and light themes, and reduced-motion preferences.
